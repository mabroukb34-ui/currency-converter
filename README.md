# محوّل العملات 💱

تطبيق ويب لتحويل العملات بواجهة عربية (RTL) وتصميم ذهبي داكن.

## المميزات
- تحويل بين أكثر من 160 عملة بأسعار لحظية (open.er-api.com)
- رسم بياني لآخر 7 أيام باستخدام Recharts (frankfurter.app)
- عكس العملتين بزر واحد + بحث فوري في القوائم المنسدلة
- جدول بأشهر 10 عملات مقابل الدولار
- وضع ليلي / نهاري محفوظ في localStorage

## التقنيات
Next.js 14 (App Router) — TypeScript — Tailwind CSS — Recharts

## التشغيل محليًا

    npm install
    npm run dev

ثم افتح http://localhost:3000

## ملاحظة
الأسعار لأغراض إعلامية وليست للتداول.
